# Edson House · interactive 3D plan

[Open the 3D viewer](https://nottsaifuture.github.io/Edson-House/)

Five-bedroom Edson House, Plumtree. Orbit the model, explore either floor, open doors, use dimensions and measurements, or enter the first-person walkthrough.

This repository contains the built viewer only. Editable source stays local. The browser receives compiled JavaScript to display the model.

Reference-led architectural interpretation. Heights, roof details, furniture and the stair flight are inferred; the front door uses an outward swing to clear the interpreted staircase. Not construction documentation.

Independent demonstration · not affiliated with or endorsed by Gilbert & Hall.
